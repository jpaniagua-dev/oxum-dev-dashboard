# Documentation

How to install, set up and use Oxum Dev Dashboard. Start with **Getting started**, then read the
page of the tab you are using.

- [Getting started](getting-started.md): install, what the machine needs, first launch, updates, a
  team configuration.
- [Settings](settings.md): every page of the settings window, and what sits under Advanced.
- [The terminal](terminal.md): tabs, panes, shells, the servers window.
- Tabs, in the order of the strip:
  - [Projects](tabs/projects.md): the watched repositories, their server, files, branch and checks.
  - [Pull requests](tabs/pull-requests.md): the pull requests that involve you, and their review.
  - [Worktrees](tabs/worktrees.md): every worktree of every project, created and removed in place.
  - [Tickets](tabs/tickets.md): Jira issues and local tickets, as a list or a board.
  - [Triage](tabs/triage.md): a sprint classified by an agent, and tickets handed over to it.
  - [Git](tabs/git.md): stage, commit, branches and history of one repository.
  - [Rules](tabs/rules.md): automations that act on their own.
  - [Vault](tabs/vault.md): secrets kept out of `.env` files and chats.
  - [Agents](tabs/agents.md): the coding agents running, and what each one reads.
  - [Extensions](tabs/extensions.md): hooks, skills, plugins, MCP servers and routines of Claude
    Code and Codex.
- [Troubleshooting](troubleshooting.md): a symptom, its cause, what to do.
- [Development](development.md): build from source, tests, architecture.

The examples use made-up names (`web-app`, `PROJ-123`): this repository is public.
