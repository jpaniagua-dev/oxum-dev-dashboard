Settings

    General

    The size of the app's text, the update notice, and a team configuration to share or to start from.

    Projects

    The repositories the dashboard watches. A folder is enough: the kind and the port are inferred from its package.json.

    Terminal

    The shell new tabs open in, and its text size. Shells installed on this machine are detected; a path you edit is kept over the detected one.

    Agent

    The coding agent the app runs for the triage, the handoff of a ticket, commit messages and reviews. Claude Code works as installed; press Test to check it answers.

    Tickets

    The Tickets tab shows Jira issues and local tickets together. Jira needs the connection below; local tickets need only their folder. The API token is encrypted for your Windows account, stored apart from the settings and never shown again: to change it, type a new one.

    GitHub review

    Off by default: the review runs, shows its verdicts and posts nothing. Turned on, the app submits reviews to GitHub as you, through the gh you are signed in with. A submitted review cannot be deleted, only dismissed.

    Rules

    Off by default. A rule watches something the app already knows (a pull request approved, a server broken, an issue assigned to you, a time of day) and acts on it on its own, which is why it has a switch of its own.
