Réglages

Interface

Cette taille est la base de toute la typographie de l’app : tout le reste (badges, en-têtes, listes) garde ses proportions autour d’elle. Le terminal, lui, a sa propre taille dans la section ci-dessous.

Projets

Un dossier suffit. Le type et le port sont déduits du package.json du dépôt quand il y en a un ; laisse-les vides pour suivre le projet automatiquement.

Terminal

Les profils sont détectés sur la machine. Modifier un chemin le marque comme personnalisé et il primera sur la détection.

Notes

Une note est un fichier .md dans ce dossier, dont le titre est la première ligne. Le dossier reste lisible en dehors de l’app. Laisse le champ vide pour utiliser le dossier de l’application.

Jira

Le jeton d’API est chiffré par Windows pour ton compte et rangé à part, jamais dans settings.json. Il n’est jamais relu vers cette fenêtre : pour le changer, saisis-en un nouveau. Un jeton donne accès à tout ton Jira, pas seulement en lecture.
