Settings

    Interface

    This size is the base of the whole app's typography: everything else (badges, headers, lists) keeps its proportions around it. The terminal has its own size, in the section below.

    Projects

    A folder is enough. The kind and the port are inferred from the repository's package.json when there is one; leave them empty to follow the project automatically.

    Terminal

    Profiles are detected on this machine. Editing a path marks it as custom, and the custom value then wins over detection.

    Coding agent

    Which CLI agent runs, and how it is called. The command is a template: everything is passed through as written, {model} is replaced by the model flag and disappears when no model is pinned, and quoted sections are kept whole. It is not a shell, so nothing is expanded or globbed.

    Three of these decide whether anything runs at all, and they fail quietly when wrong: the flag that means answer and exit (without it the agent opens its interface into a pipe and never returns), how the prompt gets in (a sprint prompt is tens of kilobytes, past what a command line accepts), and the flags that keep the run read-only. That last one is yours to get right: the pull request review trusts the template, so an agent given no restriction can write to the repository it is reviewing. Press Test after any change: it is the only thing that proves the command works.

    Pull request review

    Off by default, and that is the point: with the switch off the review runs, shows its verdicts and posts nothing. Turning it on lets the app submit reviews to GitHub as you, on your colleagues' pull requests, through the gh you are signed in with. A submitted review cannot be deleted, only dismissed.

    Rules

    Off by default. A rule watches something this app already knows, a pull request approved, a dev server broken, an issue assigned to you, or simply a time of day, and acts on it once, on its own. Every other agent in this app starts with a button; these do not, which is why they have a switch of their own.

    Jira

    The API token is encrypted by Windows for your account and stored separately, never in settings.json. It is never read back into this window: to change it, type a new one. A token grants access to all of your Jira, and not read-only access either.
