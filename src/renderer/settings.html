Settings

    Interface

    This size is the base of the whole app's typography: everything else (badges, headers, lists) keeps its proportions around it. The terminal has its own size, in the section below.

    Projects

    A folder is enough. The kind and the port are inferred from the repository's package.json when there is one; leave them empty to follow the project automatically.

    Terminal

    Profiles are detected on this machine. Editing a path marks it as custom, and the custom value then wins over detection.

    Claude Code

    Which model each run is pinned to. Leave a field empty to use whatever Claude Code itself is set to. An alias (opus, sonnet, haiku) always points at the latest version of that model; a full name (claude-fable-5) pins one. Four fields because these are four different jobs, and one answer would be wrong for three of them.

    Pull request review

    Off by default, and that is the point: with the switch off the review runs, shows its verdicts and posts nothing. Turning it on lets the app submit reviews to GitHub as you, on your colleagues' pull requests, through the gh you are signed in with. A submitted review cannot be deleted, only dismissed.

    Jira

    The API token is encrypted by Windows for your account and stored separately, never in settings.json. It is never read back into this window: to change it, type a new one. A token grants access to all of your Jira, and not read-only access either.
